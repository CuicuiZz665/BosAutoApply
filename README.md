# BOSS直聘自动投递助手

一个 Chrome 浏览器插件（Manifest V3）：登录 BOSS 直聘后，在职位搜索页点击"开始投递"，
插件会自动按你设置的条件搜索匹配的岗位、给 HR 打招呼并完成投递。

## 功能

### 搜索与匹配

- **关键词轮换搜索**：多个关键词（支持 `逗号 / 顿号 / 分号` 混用分隔）会按顺序**逐个搜索并投递**，
  直到达到投递上限或全部搜完；已投过的职位在不同关键词下重复出现时自动跳过，不会重复打招呼
- **两种匹配模式**：`命中任意一个（广撒网）` 或 `必须全部包含（精准）`；
  精准模式下关键词可分布在职位名称和职位描述里（如名称含"产品"、描述含"硬件"）
- 关键词与排除词的匹配范围包含**职位卡片上的一句话描述**，行业信息也能被排除词命中
- 按排除关键词 / 排除公司 / 薪资范围过滤，薪资自动应用到 BOSS 原生"薪资待遇"筛选器
  （自动选中与你期望区间重叠最多的档位）

### 筛选条件（自动应用到 BOSS 原生筛选器，留空则保持页面手动设置）

- **区域**（区/县，多选，支持"海淀"这类简称）+ 卡片区域文字二次过滤兜底
- **行业**（多选；若你的页面没有该项会自动跳过并提示）
- **求职类型 / 工作经验 / 学历要求 / 公司规模 / 融资阶段**

### 运行体验

- **设置热更新**：任务运行中修改排除词/薪资/话术/上限/间隔等，**无需停止重启**，
  保存后下一个职位立即按新规则执行（关键词搜索队列下次任务生效）
- **投递记录防重复**：已投/已跳过的职位本地持久化；测试或换批次时可一键
  「清空记录」重新处理；已沟通过的职位始终自动识别跳过
- 自定义打招呼话术；部分职位 BOSS 会强制先发默认招呼语，插件会点「继续沟通」
  把你的自定义话术**作为第二条消息补发**
- 自动识别并关闭挡路的通用弹窗（完善简历提示、活动广告等），保证流程不中断
- **自动加载更多职位**：兼容新版无限滚动列表与旧版分页按钮
- 完全串行、一步一动：每次点击前平滑滚动到目标元素、短暂高亮再点击，话术一个字一个字
  "打"出来——既让你能亲眼看到插件在做什么，也让操作节奏更接近真人手速
- 实时进度日志（已投递 / 已跳过 / 异常），关闭弹窗后任务仍在后台继续运行
- **一键页面诊断**：BOSS 改版导致插件失效时，点面板里的「📋 一键诊断」，
  自动检测页面结构与选择器的匹配情况并复制结果，反馈 issue 时贴上即可

## 隐私与安全

- 插件**不会**读取、存储或上传你的账号密码、Cookie 或任何登录凭证。
- 所有操作都是在你已登录的浏览器标签页里，模拟人工点击 DOM 元素完成的。
- 已投递 / 已跳过的职位 ID 只保存在你本机的 `chrome.storage.local` 中，不会上传到任何服务器。
- 插件不含任何远程代码、遥测或第三方网络请求。

## ⚠️ 使用须知（务必阅读）

1. **自动化操作可能违反 BOSS 直聘的用户协议**，包括但不限于自动打招呼、批量投递等行为，
   平台可能会因此限制或封禁账号。请自行评估风险，并在使用前查阅 BOSS 直聘的用户协议。
2. 请保持默认或更保守的操作间隔（建议不低于 3~8 秒），单次投递数量不宜设置过大，
   尽量模拟真实用户的操作节奏。
3. 打招呼话术请认真填写，避免群发无意义或不礼貌的信息，这既是对 HR 的基本尊重，
   也能降低被举报 / 限流的概率。
4. 本项目按 MIT 协议开源，不对使用本插件导致的账号限制、纠纷或其他后果负责，
   请谨慎、合规使用。

## 安装（开发者模式加载）

### 第一步：获取代码（两种方式任选）

**方式一：下载 Release 压缩包（推荐，无需安装 git）**

1. 打开本仓库的 [Releases 页面](https://github.com/CuicuiZz665/BosAutoApply/releases)
2. 下载最新版本的 `BosAutoApply-*.zip` 并解压到任意文件夹

**方式二：克隆仓库（适合会跟源码更新的用户）**

```bash
git clone https://github.com/CuicuiZz665/BosAutoApply.git
```

### 第二步：加载到 Chrome

1. 打开 Chrome，访问 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」，选择项目根目录（包含 `manifest.json` 的那个文件夹）
4. 工具栏出现插件图标即安装成功；建议点拼图图标把它固定到工具栏

## 使用方法

1. 登录 [BOSS直聘](https://www.zhipin.com) 网页版，进入职位搜索结果页
   （先手动选好城市——城市切换目前仍需手动设置）。
2. 点工具栏插件图标打开面板，填写关键词、匹配模式、筛选/排除条件、话术、上限、间隔。
3. 点「▶ 开始投递」：插件自动填入关键词搜索 → 应用筛选 → 遍历职位卡片 → 匹配 →
   打招呼 → 滚动加载更多，直到达到上限或没有更多职位。
4. 运行中可随时修改设置（实时生效）、点「停止」中断；关闭面板不中断任务。

## 常见问题

**Q：点了「开始投递」提示 "Could not establish connection. Receiving end does not exist."？**
刚刷新过扩展或刚安装后，Boss 页面需要刷新一次（`Cmd/Ctrl + R`）让插件脚本注入页面。
**每次刷新扩展后，Boss 页面都必须跟着刷新一次。**

**Q：日志全是"跳过"，投递数是 0？**
检查关键词分隔符（逗号/顿号/分号都支持）和匹配模式（精准模式要求全部包含）；
再看日志开头「共解析出 N 个关键词」是否正确。另外，之前投递/跳过的职位会被记录，
可用面板里的「🗑 清空记录」重置。

**Q：扩展页出现红色「错误」提示 CSP / javascript URL？**
历史版本问题，现已修复；旧记录可点「全部清除」。若清除后仍复现，请点开错误复制内容提 issue。

**Q：投递到一半全变成了"已处理过，静默跳过"？**
该关键词下的职位在此前运行中已处理完，换个新关键词或清空记录即可。

**Q：BOSS 页面无法打开 F12 / 控制台？**
BOSS 有反调试机制。插件内置「📋 一键诊断」按钮（面板底部），不依赖 F12，
可自动检测页面结构并复制诊断结果。

## 如果页面结构变化导致插件失效

BOSS 直聘前端会不定期改版（职位名/公司名/薪资等元素的 class 会变）。失效表现为
投递数长期为 0、日志提示"未解析出职位名称"等：

1. 点插件面板底部的「📋 一键诊断」，把自动复制的诊断结果贴到 [issue](https://github.com/CuicuiZz665/BosAutoApply/issues)
2. 或自行对照诊断结果里的 HTML，更新 `src/shared/selectors.js` 中对应的选择器数组
   （无需改动其余逻辑），再到 `chrome://extensions` 刷新插件

## 项目结构

```
.
├── manifest.json              # Chrome 扩展清单 (Manifest V3)
├── src/
│   ├── background/
│   │   └── background.js      # 后台 service worker，缓存并广播任务进度
│   ├── content/
│   │   └── content.js         # 注入到职位搜索页，负责实际的自动化流程
│   ├── popup/
│   │   ├── popup.html         # 设置面板 UI
│   │   ├── popup.css
│   │   └── popup.js           # 读写配置、控制启停、一键诊断、展示日志
│   └── shared/
│       ├── selectors.js       # 集中管理的页面选择器（页面改版时优先改这里）
│       └── matcher.js         # 纯函数：职位是否匹配用户设定的条件
└── test/
    └── matcher.test.js        # 匹配逻辑的单元测试（node --test）
```
